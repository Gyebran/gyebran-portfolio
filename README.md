# Gyebran Portfolio

This repository contains the current version of Gyebran Nauri Haikal's personal portfolio, built with React, Vite, Three.js, GSAP, Framer Motion, and Tailwind CSS.

## Highlights

- Interactive Three.js hero experience
- Responsive profile, experience, projects, certifications, skills, and contact sections
- Centralized portfolio data in `src/data/portfolio.js`
- Mobile and reduced-motion adaptations
- SEO metadata, favicon, and robots configuration
- GitHub Actions CI for lint and production build validation
